# Install and remove

```sh
gemini extensions install https://github.com/daehoonkwon-hash/klisten-toolguard-gemini-extension
```

Enter your scoped key only in the sensitive extension setting. Start Gemini CLI and inspect `/mcp`. For the first safe call, request an existing attestation that belongs to your account. Confirm any paid gate call and its spending limit before proceeding.

```sh
gemini extensions uninstall klisten-toolguard
```

Installation, native authenticated MCP connection and removal were verified with CLI 0.63.0 in an isolated profile. Actual Gemini conversation tool invocation remains NOT VERIFIED.
